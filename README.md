# Bix - تطبيق التواصل الاجتماعي للفيديوهات القصيرة

## نظرة عامة
Bix هو تطبيق تواصل اجتماعي مخصص للفيديوهات القصيرة، مبني بتقنية Flutter مع Firebase كخدمة خلفية. يوفر التطبيق تجربة مستخدم سلسة ومميزات شاملة للتفاعل الاجتماعي.

## المميزات الرئيسية

### 🔐 إدارة المستخدمين
- تسجيل مستخدم جديد
- تسجيل دخول متعدد الطرق (Google، البريد الإلكتروني، رقم الهاتف، ضيف)
- تعديل الملف الشخصي
- رفع صور الملف الشخصي
- استعادة كلمة المرور
- نظام الجلسات الآمن مع JWT

### 👥 نظام الأصدقاء والمتابعين
- إرسال طلبات الصداقة والمتابعة
- قبول/رفض الطلبات
- إزالة الأصدقاء والمتابعين
- عرض قوائم الأصدقاء والمتابعين

### 📱 المنشورات والفيديوهات
- إنشاء منشورات (نص، صورة، فيديو)
- تسجيل وتحرير الفيديوهات القصيرة
- تعديل وحذف المنشورات
- عرض الفيديوهات في الصفحة الرئيسية
- ضغط الفيديوهات تلقائياً لتوفير المساحة

### 💬 التفاعل الاجتماعي
- نظام الإعجابات والتفاعلات
- التعليقات على المنشورات
- المشاركة والنشر
- الرسائل المباشرة بين المستخدمين

### 🔍 البحث والاستكشاف
- البحث عن المستخدمين
- البحث عن المنشورات والهاشتاغات
- اقتراح الأصدقاء والمحتوى المشابه

### 🔔 الإشعارات
- إشعارات الإعجابات والتعليقات
- إشعارات الرسائل الجديدة
- إشعارات المتابعة الجديدة
- دعم Push Notifications

### ⚙️ الإعدادات والأمان
- إعدادات الخصوصية
- إعدادات الإشعارات
- تشفير كلمات المرور
- حماية البيانات والمحتوى

## التقنيات المستخدمة

### Frontend
- **Flutter 3.24.3** - إطار العمل الرئيسي
- **Dart** - لغة البرمجة
- **Provider** - إدارة الحالة
- **GetX** - التنقل وإدارة الحالة المساعدة

### Backend & Services
- **Firebase Auth** - المصادقة والتوثيق
- **Cloud Firestore** - قاعدة البيانات
- **Firebase Storage** - تخزين الملفات والوسائط
- **Firebase Messaging** - الإشعارات

### المكتبات الرئيسية
- `camera` - تسجيل الفيديوهات والصور
- `video_player` - تشغيل الفيديوهات
- `chewie` - مشغل فيديو متقدم
- `image_picker` - اختيار الصور والفيديوهات
- `video_compress` - ضغط الفيديوهات
- `cached_network_image` - تحميل وتخزين الصور مؤقتاً
- `google_sign_in` - تسجيل الدخول بـ Google
- `share_plus` - مشاركة المحتوى
- `permission_handler` - إدارة الأذونات

## هيكل المشروع

```
lib/
├── constants/          # الثوابت والألوان
├── models/            # نماذج البيانات
├── services/          # خدمات Firebase والAPI

├── screens/           # شاشات التطبيق
│   ├── auth/         # شاشات المصادقة
│   ├── home/         # الصفحة الرئيسية
│   ├── search/       # البحث
│   ├── create/       # إنشاء المحتوى
│   ├── messages/     # الرسائل

│   └── settings/     # الإعدادات

```

## التثبيت والتشغيل

### متطلبات التطوير
1. Flutter SDK 3.24.3 أو أحدث
2. Android Studio أو VS Code
3. Android SDK
4. حساب Firebase مع المشروع المُعد

### خطوات التثبيت
1. استنساخ المشروع:
```bash
git clone [repository-url]
cd bix
```

2. تثبيت التبعيات:
```bash
flutter pub get
```

3. إعداد Firebase:
   - إنشاء مشروع Firebase جديد
   - إضافة التطبيق للمشروع
   - تحميل `google-services.json` ووضعه في `android/app/`
   - تفعيل Authentication, Firestore, Storage

4. تشغيل التطبيق:
```bash
flutter run
```

### بناء APK للإنتاج
```bash
flutter build apk --release
```
